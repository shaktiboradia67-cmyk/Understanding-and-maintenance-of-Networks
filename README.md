Ans.> # 🌐 Networking Hardware Devices

## 📌 Overview
Networking hardware devices are physical components used to connect computers and other devices, enabling communication and data sharing over a network.

## 🖥️ Types of Networking Hardware Devices

| No. | Device | Main Function | Real-Life Example |
|:---:|---|---|---|
| 1 | **Modem** | Connects a home or office network to the internet service provided by an ISP (Internet Service Provider). | Used at home to connect to the internet through an internet provider. |
| 2 | **Router** | Connects different networks and directs data between them. It allows multiple devices to share an internet connection. | Used at home to share the internet with phones, laptops, and smart TVs. |
| 3 | **Switch** | Connects multiple devices within a Local Area Network (LAN), allowing them to communicate with each other. | Used in a school computer lab to connect multiple computers to the same network. |
| 4 | **Access Point (AP)** | Provides Wi-Fi connectivity, allowing wireless devices to connect to a wired network. | Used in offices to provide Wi-Fi access to employees' laptops and smartphones. |
| 5 | **Network Cable** | Transfers data between network devices through a physical wired connection. | An Ethernet cable connects a desktop computer to a router or switch. |

## 🔍 Quick Summary

- **Modem:** Connects to the internet service.
- 
- **Router:** Directs data between networks.
- **Switch:** Connects devices within a local network.
- **Access Point:** Provides wireless network access.
- **Network Cable:** Transfers data through a wired connection.

## 🎯 Conclusion

Each networking hardware device has a specific role in building a reliable network. Together, these devices help computers, smartphones, and other digital devices communicate and access the internet efficiently.

## Comparison Between Router and Switch

| Basis of Comparison | Router | Switch |
|---|---|---|
| **1. Main Use** | Connects different networks, such as a local network to the internet. | Connects multiple devices within the same Local Area Network (LAN). |
| **2. Typical Location** | Commonly found at home gateways, offices, and network edges. | Commonly found in office networks, computer labs, and server rooms. |
| **3. How Data Is Handled** | Forwards packets between networks using IP addresses. | Forwards Ethernet frames using MAC addresses. |
| **4. OSI Layer** | Primarily operates at Layer 3 (Network Layer). | A typical Layer 2 switch operates at Layer 2 (Data Link Layer). |
| **5. Data Destination** | Uses a routing table to select the next hop for data packets. | Uses a MAC address table to forward frames to the appropriate port. |
| **6. Broadcast Domains** | Typically separates broadcast domains between routed interfaces. | Devices in the same VLAN generally share one broadcast domain. |
| **7. Internet Connection** | Commonly connects a local network to the internet service provider. | Connects local devices to each other and usually to a router. |

### Conclusion

A router connects different networks and directs data between them, while a switch connects devices within a local network and forwards data to the appropriate device.

### Key Difference

- **Router:** Connects networks.
- **Switch:** Connects devices within a network.
